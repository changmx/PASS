单文件项目
==========

GUI 支持普通独立 JSON 输入和单文件 ``.passproj`` 项目。
顶部 **文件** 菜单区分 JSON、项目以及导出操作。

保存与打开
----------

独立模式下，**保存 JSON** 和 **JSON 另存为** 写入普通 PASS 输入。
项目模式下，**保存项目** 将所有输入 JSON、输入依赖、源文件和生成设置写入一个容器。
``Ctrl+S`` 根据当前模式选择保存目标。**打开 JSON** 打开独立文档，
不会隐式导入当前项目；后者使用 **导入 JSON 到项目**。
替换文档或关闭窗口时，可以先保存未保存的修改。

**从当前输入创建项目** 将当前配置打包。可以继续导入其他 JSON，
通过输入选择框切换。项目复制所引用的粒子分布、偏移表、RF 表和磁铁 ramping 文件，
也保留导入前的原始 JSON、MAD-X TFS 和生成设置。
缺失输入会报告其在 JSON 中的位置，阻止保存不完整项目。
在 **项目内容** 中还可以添加其他源文件。

容器格式
--------

格式版本 1 使用标准 ZIP/ZIP64，元数据采用 UTF-8 JSON：

.. code-block:: text

   manifest.json                  # 格式/PASS 版本、输入和文件清单
   configs/<input-id>.json         # 普通 PASS 输入 JSON
   assets/<asset-id>/<filename>    # 原始输入/源文件字节
   recipes/<index>.json            # 生成设置和源文件引用

输入显示名称与稳定 ID 分开保存。配置采用相对路径引用资产；
清单记录 SHA-256 校验和与依赖索引。移动项目只需复制一个文件，
不需要携带临时编辑缓存；运行输入不依赖原电脑路径。
源文件是快照，外部同名文件变化不会自动改变项目。

保存时先写入并校验新归档，再替换旧文件。版本 1 拒绝不支持的格式版本、
不安全路径、重复条目、校验和或依赖索引不一致。
限制为 100,000 个条目、256 GiB 解压后总大小以及每个 JSON 条目 64 MiB。
大型项目保存需要写入完整新归档的时间和额外磁盘空间。
大型仿真输出不自动归档；显式添加为输入或源文件的内容会被内嵌，
包括作为下一次输入使用的结果文件。

查看和复用参数
--------------

**项目内容** 列出输入 JSON、源文件和生成设置。
选择 JSON 或其中的命令，查看参数表与原始文本；可以复制单个值或当前命令 JSON。
**复制命令到当前输入** 还会带入引用的空间电荷配置、切片器和文件依赖。
目标中已有名称保持不变；导入名称冲突时添加数字后缀。
也可以只读打开另一份项目作为参数来源。

TFS 和 CSV 提供最多 500 行的数据预览。文本预览限制为 2 MiB，参数表限制为 5,000 项；
可以随时导出完整原文件。二进制文件显示元信息并提供导出。
向独立 JSON 复制的依赖在保存时放入旁边的 ``<json-name>_files`` 目录。

生成设置用于记录命令来源。**载入生成设置** 恢复表单，供预览和插入，
不会自动覆盖已经手动编辑的命令。
普通 JSON 保存生成后的命令，不保存这部分额外生成元数据。

导出
----

**导出当前 JSON** 仅输出配置副本，不包含引用文件，
也不改变当前正在编辑的文档。
**导出可运行输入包** 将运行页所选输入及其依赖写入 ZIP，附带 ``run.py`` 和英文使用说明。
完整解压后，在安装了 PASS 的环境执行 ``python run.py``。
启动脚本以解压目录为基准解析路径，运行输入包不需要安装 Qt。

运行
----

运行页选择 Beam 0，以及可选的另一份 Beam 1 输入。
项目可保存多份候选配置，不代表引擎一次执行全部配置。
相对输出目录以 JSON 或已保存项目所在目录为基准；
未保存项目以当前工作目录为基准。

启动子进程前，GUI 校验所选全部输入，
将固定快照写入 ``<output>/input_snapshots/<run-id>``。
快照 JSON 使用指向已复制资产的绝对路径；输出保存在项目临时缓存以外。
之后继续编辑不会改变已经启动的任务。“停止”终止子进程。
初始化或跟踪异常会显示为运行失败，包括引擎只记录日志、没有重新抛出的错误。

已应用的参数修改支持撤销/重做；当前文本框和 JSON 编辑器保留各自的文本撤销/重做。
保存前需要处理尚未应用的属性或 JSON 修改。
GUI 新建高斯束团使用 1e-6 m rad 的正横向发射度，运行前拒绝零范围的高斯采样。
