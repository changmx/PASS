图形界面配置流程
================

使用 ``python -m pip install --editable ".[gui]"`` 安装可选界面，再通过
``python -m PASS.gui`` 或 ``pass-gui`` 启动。配置页编辑追踪引擎使用的输入文件；
运行页和绘图页保持独立。

顶部集中放置文件、配置、运行、绘图、工具、帮助，以及深色/浅色/跟随系统的主题选择。
默认窗口为 1200 × 760 逻辑像素，窗口和侧栏尺寸、主题及列偏好保存在本机。
中间执行序列按引擎的位置分箱与命令优先级排序。名称、Command、位置为必备列；拖动表头分隔线调整列宽，
右键选择其他列。校验放在执行序列工具栏，但检查完整当前输入及文件依赖。
完整报告、规则与命令行检测参见 :doc:`input_validation`。
当前模式适用的属性字段展开，互斥选项隐藏或禁用，长表单在属性栏内滚动。
JSON/项目保存、源文件打包、参数复用和固定运行快照参见 :doc:`project_files`。

左侧组件库的展开栏按选项数量占用高度，多余空间留在整个列表底部。
启动时仅 **输入配置（必需）** 展开，其余一级栏目以及空间电荷子菜单默认折叠。
**物理效应** 依次包含 **空间电荷**、**尾场**、**束束效应**、**电子云**，
空间电荷与尾场均可独立展开或折叠。尾场包含 **全局配置**、**插入尾场切片**、
**尾场点**；束束效应和电子云仍为禁用的预留入口。

帮助与本地文档
--------------

主题按钮旁的 **帮助** 菜单提供 **在线说明文档** （中文 / English）、**源代码**、
**阅读本地文档** （中文 / English）、**重新编译本地文档** 和 **关于 PASS**。
网页链接和本地 HTML 均使用系统默认浏览器打开。

本地编译需要完整 PASS 源码，并在启动 GUI 的同一个 Python 环境中安装文档依赖。
在源码目录执行::

   python -m pip install --editable ".[gui,docs]"

每次点击 **重新编译本地文档** 都使用 GUI 的 Python 解释器，对中英文文档进行完整的
Sphinx HTML 构建。编译在独立进程中运行，界面仍可操作。进度窗口显示实时日志，
并提供停止按钮；关闭进度窗口后编译继续，可通过帮助菜单中的 **查看编译日志** 重新打开。
编译期间禁止重复启动；编译过程中关闭 PASS，会询问是否停止编译后退出。

每次构建写入独立的 ``docs/build/gui/<timestamp-id>/`` 目录。只有构建成功、没有
Sphinx 警告且各语言首页均存在时，才更新 ``docs/build/gui/latest.json`` 指向新结果。
失败或停止编译后，上一次成功的文档仍可阅读。构建目录保留，重新编译不会删除旧结果。
**阅读本地文档** 直接打开已保存的结果，不会触发重新编译；没有 GUI 构建结果时，
尝试读取常规命令行输出 ``docs/build/html/``。尚无本地页面时，提供立即编译和在线文档入口。
缺少源码、依赖或文件系统错误会显示原因和处理提示；GUI 不会自动安装依赖。
不包含源码目录的普通安装可阅读在线文档，但无法本地编译。

**关于 PASS** 显示当前安装版本、项目简介、作者、机构、版权和 Apache License 2.0。
说明文档、源代码和问题反馈均为可点击链接。许可证优先在只读窗口显示本地全文，
本地文件缺失时打开在线许可证。**复制版本与环境信息** 复制 PASS、Python、PySide6
版本、操作系统和架构，便于反馈问题。

工具
----

**工具** 与配置、运行、绘图同级，左侧可选择束流参数计算器、共振线图、RF 桶、
相空间绘制及发射度计算、磁铁参数换算和激励计算。计算独立于当前仿真输入。
粒子质量固定采用 AME2020、NIST/CODATA 和 PDG 数据；所有粒子的 Ek 均按实际静止质量的 u 数归一化，使用 MeV/u。
详细公式窗口包含可点击的来源网站。单位、物理约定和使用流程参见 :doc:`gui_tools`。

主题与控件
----------

深色主题采用 `One Dark Pro 的配色 <https://github.com/Binaryify/OneDark-Pro>`_，
以炭灰背景、蓝色强调和柔和灰色文字呈现；浅色主题使用相同的控件与层级结构。
界面使用 12 逻辑像素字体，优先 Segoe UI Variable Text，中文回退至 Microsoft YaHei UI。
JSON 源码和运行日志使用等宽字体：优先 JetBrains Mono，未安装时使用 Consolas 或 Cascadia Mono。
源码的键、字符串、数值与布尔值分别着色。无需另外安装字体。

**输入配置（必需）** 标出输入配置入口。各级标题和选项均左对齐，
子级逐层向右缩进，以细竖线连接，并用轻微底色区分主标题；不依赖颜色判断层级。
下拉框右侧始终显示箭头和分隔线。复选框以对号表示选中，禁用时保留对号。
所有页面及对话框的下拉选项框均禁止用鼠标滚轮直接切换当前选项，包括获得焦点时；
使用鼠标时先单击展开列表，再单击选择。展开的列表仍可用滚轮浏览。

校验、表格编辑、消息和文件选择窗口均跟随当前主题。Windows 11 使用系统接口设置
原生标题栏的背景与文字颜色，Windows 10 使用系统支持的深色标题栏标志；
窗口仍保留系统移动、缩放和贴靠功能。文件选择使用 Qt 对话框，以使内容区也保持主题一致。

属性顺序与分区
--------------

属性标题旁显示只读的 ``Command`` 类型，可编辑参数从名称、位置 ``s``、长度开始。
元件本身的场强和几何参数排在前面，随后是 ``Model``、``Integrator`` 与切片数。
界面的排列独立于 schema 的继承顺序与打开的 JSON 中键的排列。

例如二极铁 ``SBend`` 的顺序为：名称、``S (m)``、``Length (m)``、``K0L``、
``E1 (rad)``、``E2 (rad)``、``Hgap (m)``、``Fint``、``Fintx``、``Model``、
``Integrator``、``Num slices``，之后依次为 **场误差**、**孔径**、**Ramping**、
**内部空间电荷** 分区。每个分区包含其开关与相关参数，使用轻边框保持整体感，
全部常驻展开，不设折叠按钮。未启用的内部空间电荷参数仍显示并禁用。

其他磁铁沿用相同次序与分区，只显示各自支持的参数。射频腔的射频数据、
激励器的频率与幅度调制、Slicer 的切片范围、监测器的参考光学与分析范围，
也按用途分区；保存电场、电势、电荷密度及保存圈数集中在 **诊断输出** 中。
Twiss 保留起点光学、终点光学与传输设置分区，Injection 保留 bunch 编辑器。

模块职责
--------

``PASS/validation`` 是 GUI、``python -m PASS.validation`` 命令行检测及仿真启动前检查
共用的校验模块，不依赖 Qt。``PASS/gui/validation.py`` 仅负责后台检测线程与报告窗口。
``app.py`` 负责界面组装，``appearance.py`` 负责主题、字体、图标与窗口外观，
``structured.py`` 提供结构化参数控件，``project.py`` 处理项目打包与资源，
``workspace.py`` 处理文档工作流，``optics.py`` 提供光学配置辅助，
``runner.py`` 提供独立运行入口。这些职责分开维护，避免将文件读写、校验和控件实现全部堆入主窗口文件。

结构化数组参数
--------------

属性栏中的数组和嵌套参数使用专门控件，不需要输入 JSON 括号、逗号或记忆数组排列。
完整输入仍可通过 JSON 源码页编辑。

* **保存圈数**：每行填写起始圈、结束圈（含上限）和正整数步长。
  **添加单圈** 使起止圈相同，**添加区间** 添加一段范围；**全部圈** 填入当前仿真范围。
  空表表示不保存。圈数从 0 开始，单圈写为 ``[turn]``，区间写为 ``[start, end, step]``。
* PhaseAdvanceMonitor 的 **分析圈数范围**：结束圈不包含在范围内，
  每段至少包含两圈，空表表示不分析。
* **手动插入粒子**：六列数值表分别填写 x、px、y、py、束团相对 z 和 dp/p。
  每行一个粒子，界面显示行数对应的粒子数量，不能超过首次注入的宏粒子数。
  手动坐标替换该注入块内的粒子，不会额外增加配置中的粒子总数。
* **孔径参数**：按形状显示带单位的尺寸输入。
  圆形、矩形、椭圆、矩形与圆/椭圆交集、跑道形和八边形分别显示半径、半宽、半轴或切角等参数，
  单位为 m；多边形使用有顺序的 x/y 顶点表。
  在同一表单内切换形状，会保留各形状已经填写的尺寸。
  应用时拒绝无效尺寸、退化多边形及无效的八边形切角。
* **动量接受范围**：提供自定义开关，以及 dp/p 上下限；
  取消自定义时使用引擎默认的 -1 至 1。
* **KiL / KiSL / Field error KNL / Field error KSL**：使用“阶次—数值”表。
  0 阶为二极，1 阶为四极，2 阶为六极；未列出的阶次补零，删除一行不会改变更高阶次。
  不允许重复阶次。积分强度的 n 阶单位为 m 的 -n 次方。
* **GPU 设备列表**：逐行输入整数设备编号，检查重复，设备数量由列表自动计算；
  CPU 后端下禁用该列表。
* Slicer 的 **显式切片范围**：使用 z 上下限数值框，选择 ``explicit`` 后启用，
  ``auto`` 不写入显式范围。元件的 **内部空间电荷** 提供开关、命名配置选择、kick 数、
  孔径、输出开关与独立保存圈数表。

表格支持数值单元格、增删行和较大的 **表格窗口**。
右键可粘贴表格行、复制、调整行序或清空；表格获得焦点时也支持 ``Ctrl+V``。
可以直接粘贴制表符或逗号分隔的数值行，无需转换为 JSON；无效粘贴不会改变已有数据。
表格窗口支持一次添加多行，点击 **应用表格** 前修改保留在窗口内；
之后再应用属性表单以更新输入。数值编辑支持科学计数法并保留很小的浮点数。
保存时也会提交正在编辑的数值单元格。即使打开的 JSON 省略了可选 bunch 参数，
界面仍会显示这些参数的默认控件。

空间电荷
--------

使用 **SC 切片** 建立 ``z_periodic`` Slicer。通用切片默认 ``z_rel``；
尾场使用 ``z_rel`` 或 ``arrival_phase``。兼容项 ``Periodic`` 由 ``Coordinate`` 决定，
旧输入仅有 ``Periodic=true`` 时仍解释为 arrival phase。
切换到 ``arrival_phase`` 自动选择等长度切片和显式区间 ``[-C,0]``；
以后修改环长时需重新检查区间。切片不改写连续粒子 z，RF 不重新划分已保存区间，
结构重分组后必须再次显式执行 Slicer。

在 **物理效应** 中点击 **空间电荷** 标题，可展开或折叠其子菜单，交互与外层模块一致。
折叠操作本身不修改项目，也不丢弃当前表单；没有返回菜单项。

* **全局配置**：管理模块开关、命名配置、切片集引用、PIC 网格和求解器。
* **插入计算点**：手动在指定位置插入引用命名计算配置的 ``SpaceCharge`` 命令。
  作用长度和输出选项等计算点参数的含义不变，参见 :doc:`space_charge`。

全局配置中的选项按 ``Method`` 和 ``Solver`` 联动：

* ``pic`` 只列出 ``fft_free_space``、``fd_dirichlet``、``dst_dirichlet``，
  沉积方式默认 **CIC**，也可选 TSC。
* ``frozen`` 和 ``quasi-frozen`` 只列出圆形高斯、椭圆高斯、均匀圆盘、均匀椭圆
  四个自由空间解析求解器，沉积方式仍显示但禁用。
* ``frozen`` 启用固定源分布中心 ``Center X/Y``，并按公式启用对应尺寸：
  圆形高斯为 ``Sigma``；椭圆高斯为 ``Sigma X/Y``；均匀圆盘为 ``Radius``；
  均匀椭圆为 ``Semi-axis A/B``。只有椭圆公式启用 ``Angle``。
* ``quasi-frozen`` 根据每个切片当前粒子的统计量计算中心、尺寸和方向，
  固定分布参数输入框仍显示但禁用。解析模式下网格参数用于诊断输出采样和默认孔径。

``Center X/Y`` 是源分布中心；``Angle`` 是局部 x 主轴的逆时针转角（rad）；
``Sigma`` 是高斯单轴 RMS 尺寸；``Radius`` 是均匀圆盘的外半径；
``Semi-axis A/B`` 是均匀椭圆的半轴。中心和尺寸单位均为 m。
这些尺寸描述电荷源分布，不是管壁或粒子损失孔径。切换选项后，不适用字段仍显示但禁用，
保存时写为 null，避免将其他公式的参数带入当前配置。

**网格范围输入** 可选 **全宽** 或 **半宽**，两个方向均以 m 为单位填写；
不使用的一组保存为 null。节点间距由范围和节点数计算。

配置中不再包含 ``Chamber``。各 SC 点设置 ``Aperture type`` 和 ``Aperture value``，
默认解析为网格同尺寸矩形。孔径用于损失判断，并在 FD/DST 中同时定义导体壁。
不同 FD 管壁使用独立缓存求解器，共享配置网格；FFT 共享核，孔径仅用于损失。
初始化时检查有限 PIC 孔径完整位于网格内，DST 必须使用完整网格矩形。
管壁上或外部粒子在求场前损失。

解析求解器不能保存电势，界面不允许新启用该项；已导入的 true 可以取消。
内部 SC 继承父元件孔径，冲突的旧子孔径会被引擎覆盖。
``Num kicks`` 决定内部 SC 节点数，与父元件输运 ``Num slices`` 不同。

注入、时钟、RF 与脉冲元件
-------------------------

Injection 应用表单时保留合法 harmonic ID 排列；新增/复制束团分配新槽，删除槽时压缩其后的编号。
批次摘要显示计划总量、首次/后续批次数量、末次注入圈和宏粒子权重；新增束团沿用已有权重。
分布文件支持 ``sequential`` 和 ``repeat``。
随机种子与参考到达时间可清空为 null。电极损失使用独立 ElSeparator 配置。
整数输入支持大粒子数，不受有符号 32 位上限限制。

全局配置始终提供 ``Reference clock``，包括旧 JSON 未填写该键时。
关闭自定义时使用初始 harmonic ID=0 束团决定的默认时钟；启用后填写时间原点与常频，
或递增的时间/频率表。频率乘环长必须小于光速。规定时钟不跟随跟踪束团的瞬时能量变化。

RFCavity 分量支持内联/文件、谐波/直接频率模式。电压、相位与直接频率可选择常数或共享
``Time (s)`` 的时间表。文件需有 TIME/VOLTAGE/PHASE，直接频率模式另需 FREQUENCY，
谐波模式的文件则不得包含 FREQUENCY；应用时清除不适用的互斥输入。
物理波形预览使用跟踪器相同的频率积分，绘制各分量与总电压，可指定物理时间窗口。
预览不计算多谐波势阱。旧腔级参数和按圈 RF 文件需要按物理时间迁移，不能只改字段名。

元件库提供 Bump 与新版电压/几何 ElSeparator。必填物理量保持空白，填完才能应用。
Bump 预览 TIME/HKICK/VKICK，并可将两平面 CISP CSV 在共同物理时间区间转换为 TFS。
预览的参数校验、文件路径、TFS 格式、数据及单位错误均显示中文说明。
踢量为积分 ΔP/P0；预览包含时间偏移与表外零值约定。
**预览ES** 显示倾转电极及开放场隙，真空孔径独立处理。
ES 的 **硬件参数** 分组使用中文标签：电压、场隙宽度、电极高度、电极中心、
隔板位置、隔板厚度和倾角；保留对应单位及原有 JSON 参数名。
须填写 Gap、Electrode height 和 Septum position；缺项会提示具体字段。
电压未填时允许只预览几何，不计算电场；应用和运行仍要求填写电压。
Distribution File Mode 的输入框和展开列表按选项文本加宽，支持完整查看 sequential/repeat。
S 是出口，入口为 S-Length；零电压仍有材料损失，零长度不产生电压脉冲。
旧 EX/EY/EXL/EYL 不能推断出电压、gap 和 height，须明确填写新版物理参数。

Exciter 配置提供 tune/频率选择及 FM/AM 字段联动。
普通磁铁的 ramping 尚未实现，界面不允许新启用。

尾场与结果文件
--------------

**尾场 → 全局配置** 管理总开关及命名模型/求解器配置。打开时将已有尾场点的内联
参数分别收集为独立命名配置，不合并原来的定义。应用配置重命名时同步更新点引用；
仍被引用的配置不能删除。**尾场点** 设置配置引用、位置、切片集和单点开关。
总开关与单点开关均开启才执行；即使引用同一配置，各点也保留独立历史状态。
旧的内联 ``Groups`` 输入仍受支持。JSON/API 表达见 :doc:`wake_field`。
配置内可添加、复制、移除命名求解组和分量。
支持 direct、fft、recursive、modal、partitioned_fft、time_fft 六类求解器，
history、网格、记忆长度和周期边界控件随模式变化。
编辑器覆盖九类模型、custom 分量的空间幂次，以及 fixed/factorized/ideal 速度模型，
由共享 schema 检查组合。文件模型要求明确单位、坐标轴、符号、积分量约定和 reference beta，
不会猜测未知外部文件约定。

绘图页支持 CSV、TFS 和 DistMonitor 一维 HDF5 列。
可同时载入多个文件，选择 beam/bunch/turn 快照，筛选存活/损失粒子和注入批次，
查看配套参考量与未注入粒子计数。
仅对拥有配套逐行或快照参考时间与 beta 的存活粒子生成 ``arrival_time_s``；
损失粒子的冻结坐标不使用后续活粒子参考量换算。
缺失数值不会打乱列之间的行对应。多维 SC 场文件需使用其专门分析程序，不能当作粒子表。

Twiss 与光学
------------

组件库按以下顺序排列：

1. **从 MAD-X 文件导入 Twiss 点**。
2. **插入单圈传输矩阵**。
3. **生成平滑近似 Twiss 序列**。
4. **插入 Twiss 传输点**。

MAD-X 入口支持下述采样方式。两个生成器均先点击 **预览生成**，再点击
**插入到 Sequence**。预览不修改项目，显示命令数量、位置范围、计算得到的 beta、
步长、总相位推进和前 100 个点。插入时写入全部生成点，包括未在预览表格显示的点。
名称冲突时自动添加数字后缀，预览显示最终名称。若同一环周范围内已有光学传输，
预览会提示新增传输可能造成重复传输。

修改生成参数会使预览失效，并禁用插入按钮，直到重新预览。
序列、全局周长或未确认的 JSON 发生变化，也会阻止插入旧预览。
周长默认读取全局值，插入时将全局周长同步为生成器显示的值，并保留已有命令。
离开已修改的生成器时，界面会询问是否放弃尚未插入的草稿。

MAD-X 采样方式
~~~~~~~~~~~~~~

**采样方式** 默认选择 **保留原始位置**。选择 **等间距插值** 后启用正整数
**一圈分段数 N**，生成从 0 到 C、间距 C/N 的 N+1 个基础点。
该模式禁用并忽略 **是否合并连续 Drift**，不设高级插值参数菜单。

点击 **预览导入** 可查看实际间距、基础点数、附加拆分位置数、Twiss command 数量
和水平、垂直两个平面的完整相位差，再点击 **导入到 Sequence**。
导入结果仅包含重采样点及必要拆分点，不同时导入原始 Twiss 行。
导入仍追加到当前 Sequence；若用于替换已有传输，应先移除那部分旧传输。
修改采样参数或源文件后，缓存的导入结果会失效。

插值共同使用原始相位、beta 和 alpha：在每个源区间内，用五次 Hermite 多项式
表示累计相位，其一阶、二阶导数在两端匹配 beta 和 alpha 给出的值，
再由同一个多项式求出 beta、alpha。色散采用三次 Hermite 插值，在支持的无耦合、
参考轨道近轴约定下，以 DPX 作为 DX 的斜率。公式及 Python API 见 :doc:`input_generation`。

源文件必须覆盖 0 至 LENGTH，beta 为正，累计相位保持展开、递增，并与 Q1/Q2 一致。
缺少端点时不做外推。程序检查整个相位多项式的斜率为正；若检查失败，需要从 MAD-X
导出更密集的源数据。仅增加 N 不能恢复源文件中缺失的信息。
源值和总相位差保持到浮点精度；核对 TFS 头中的工作点时允许文件输出舍入误差。

薄元件和场误差保留原始位置，并在此处拆分 Twiss 传输。
同一 S 的不同光学状态保留为入端、出端状态，通过零长度 Twiss 传输表达光学跳变。
因此最终位置不一定全部等间距。同一位置先执行 Twiss，再执行附加薄元件或场误差。
源光学已包含设计线性聚焦，显式插入的薄元件是附加作用，不会从源光学中扣除或替换
设计聚焦。因此，附加线性误差仍可能改变追踪工作点，而重采样的基础光学保持源工作点。

单圈传输
~~~~~~~~

输入名称、周长 :math:`C>0`、tune :math:`Q_x,Q_y` 和一组周期光学参数
:math:`\alpha_x,\alpha_y,\beta_x,\beta_y`，表单按此顺序排列。
Beta 必须为正，由用户独立输入，不使用平滑近似公式推导。
水平色散 :math:`D_x`、色散导数 :math:`D'_x` 和单圈色品 ``DQx``、``DQy``
也直接显示在同一表单中，不设高级参数折叠区。所有数值输入必须有限。

生成器将 alpha、beta 和色散复制到两端，设置 ``S previous (m) = 0``、
``S (m) = C``，起点的水平和垂直 ``Mu`` 为零，终点分别为 :math:`Q_x,Q_y`。
因此，虽然两端周期光学函数相同，传输长度仍为 :math:`C`，相位推进仍为
:math:`2\pi Q`。

纵向传输支持 ``off``、``drift`` 和 ``matrix``。只有 ``matrix`` 模式启用
纵向 tune :math:`Q_s`；终点 ``Mu z`` 为 :math:`Q_s`，起点为零。
其他模式生成的纵向相位推进为零。引擎的 matrix 模式还使用束团纵向尺寸和动量展宽，
drift 模式使用滑移因子和传输长度。追踪公式参见 :doc:`twiss`。

平滑近似
~~~~~~~~

输入 :math:`C>0`、正的完整 tune :math:`Q_x,Q_y` 和正整数 **一圈分段数**
:math:`N`。计算平滑近似 beta 时，不应只填写 tune 的小数部分，例如应输入
9.47，而不是 0.47；表单标签标明了“完整工作点”：

.. math::

   \beta_x = \frac{C}{2\pi Q_x},\qquad
   \beta_y = \frac{C}{2\pi Q_y},\qquad
   \Delta s = \frac{C}{N}.

界面以 ``num_points=N+1`` 调用 ``generate_smooth_twiss``，得到 :math:`s=0`
处的初始单位传输点，以及结束于 :math:`C` 的 :math:`N` 段传输。
位置为 :math:`s_i=iC/N`，相位线性分配，每段色品为 ``DQx/N`` 和 ``DQy/N``，
初始点色品为零。名称使用用户指定的前缀和点序号，短步长不会因位置舍入导致重名。

Alpha 默认为零。常数 alpha、色散、色散导数和单圈色品直接显示在表单中，
不设高级参数折叠区，保留现有生成器的行为。
标准平滑光学使用零 alpha；非零常数对应自定义传输矩阵序列。
纵向模式与单圈表单一致。该入口仅生成 ``Twiss`` 命令，不生成 ``SpaceCharge`` 计算点。

手动传输点与后续编辑
~~~~~~~~~~~~~~~~~~~~

原 **Twiss** 入口改为 **插入 Twiss 传输点**。一个命令描述两端之间的传输，
因此表单分为 **起点光学参数**、**终点光学参数** 和 **传输设置**。
``Mu`` 为累计相位，单位为周（:math:`2\pi`），不是弧度。

两个生成器均写入普通 ``Twiss`` 命令；项目还会保存生成设置和 MAD-X 导入源文件。
插入后或重新加载 JSON 后，在序列中选择生成的命令，逐个编辑两端参数。
独立输入使用 **保存 JSON**，完整项目使用 **保存项目**。
在 **项目内容** 中可以载入生成设置，重新预览和插入，不会自动覆盖已经手动修改的命令。

Exciter 预览使用实际局部参考到达时间与连续 z： ``t = T_start + elapsed - z/(beta*c)``，名义束团槽位不平移该预览。RF 命令属性使用 Components 列表配置规定的物理时间波形。
