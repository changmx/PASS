自动绘图

将顶层 "Is plot figure": true``（Python 字段 ``is_plot=True）开启后， PASS 会在跟踪正常结束、监视器完成文件写入后读取结果并生成图片。默认值为 false。停止或失败的运行不会启动自动绘图。

绘图使用已保存的数据，同一入口也可以处理历史结果，无须重新跟踪。 这一步不需要 GUI、Qt 或 GPU。

对已有结果绘图

传入包含统计文件、distribution/ 和 particle/ 子目录的单次结果目录， 而不是输出根目录：

python -m PASS.plot output/2026_1029/1036_59
python -m PASS.plot output/2026_1029/1036_59 --format png pdf --dpi 300 --bins 80
python -m PASS.plot output/2026_1029/1036_59 --output figures/review

相对路径以终端当前工作目录为基准，包含空格的路径需要加引号。 默认图片保存在所选运行目录内的 plot/；--output 只修改图片输出位置。

选项

对应的 Python 调用返回绘图记录：

from PASS.plot.plot_main import plot_run

manifest = plot_run(
    "output/2026_1029/1036_59",
    save_dir=None,
    formats=("png", "pdf"),
    dpi=300,
    bins=80,
)

损失百分比

图片直接使用已保存的统计矩及损失百分比，不从部分粒子重新计算。 纵轴范围按各监视器数据自适应。全程为零的损失率仍正常绘制。

所有已记录的粒子 ID 和全部有效轨迹样本均参与绘制，不限制粒子数，也不对历史记录抽样。 前两行使用细线，投影使用小散点。通过 tag > 0 排除尚未注入及已损失记录； 无效样本会断开逐圈曲线。不生成冗长的逐粒子图例。 这些投影叠加了保存圈范围内的轨迹，而 DistMonitor 投影是某个时刻的分布快照。

坐标与风格

图片采用白色背景、内向刻度，保留坐标标签和单位、必要的短图例及分布计数色条。 不显示标题、参数说明框，也不自动叠加 Twiss 椭圆或 RF bucket。 同图中的水平／垂直统计曲线采用蓝色／橙色；分布计数使用 jet 色图，空网格留白。

横向位置使用 mm，纵向位置使用 m，RMS 发射度使用 mm mrad。 已保存的横向动量为 \(p_x=P_x/P_0\)、\(p_y=P_y/P_0\)， dp 为 \(\delta=(P-P_0)/P_0\)。这些量按 \(10^{-3}\) 缩放显示， 不标成斜率或实际纵向动量。

StatMonitor 的 zAverage、sigmaZ 使用按周长折叠的坐标。 源文件元数据明确标识该约定时，轴标签包含 fold；缺少这类元数据的独立 CSV 使用通用 z 标签。分布和粒子图保留已保存的连续束团相对坐标 \(z\)； 绘图不加上 zCenter，也不折叠这些坐标。 坐标约定见 纵向坐标与参考到达时间。

保留完整有效坐标范围，不平滑数据，也不按百分位裁剪。 PDF 中密集数据图层栅格化，坐标文字和刻度保留为矢量元素； 栅格化控制文件大小，不减少参与绘图的数据。

文件及诊断

默认目录布局为：

<run>/plot/
    statistics/
    distribution/
    particle/
    manifest.json

图片文件名保留来源标识，包括源文件中的束流、束团、监视器及圈号等信息。 已有图片予以保留，再次绘图时使用未占用的文件名后缀，绘图记录也采用该规则 （manifest_2.json 等）。 绘图记录包含输入来源、生成文件、绘图设置、跳过记录和失败信息。

支持已保存的 HDF5、TFS 表格，统计结果还支持 CSV。 同名文件仅处理一份，优先使用 HDF5 而不是配套文本副本。 绘图只读取原始结果，不修改它们，也不重新运行模拟。 单份输入绘图失败时会报告错误并继续处理其他输入。 自动绘图失败与跟踪成功状态分别报告；图片输出不完整时应查看绘图记录和日志。
